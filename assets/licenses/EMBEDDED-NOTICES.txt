EMBEDDED NOTICES FOR LAWH
=========================

Notices for code and data inside the lawh binary that Rust licence tools don't report.

THIRD-PARTY-LICENSES.txt, in each release archive, is made by cargo-about from each crate's
declared licence and licence files. cargo-about doesn't read NOTICE files
(https://github.com/EmbarkStudios/cargo-about/issues/195), and it can't see data that a crate
compiles in under the data's own terms: citation styles, syntax definitions, hyphenation
patterns. Apache-2.0 section 4(d) asks for a crate's NOTICE to travel with the binary, and the
data licences ask for their notices too. So they are copied here verbatim, each with the crate
version it belongs to and the address it was taken from. release.yml appends this file to the
cargo-about output for each target; the result is THIRD-PARTY-LICENSES.txt.

Keep this file in step with Cargo.lock. When Typst is bumped (it brings typst-assets, hayagriva,
citationberg, hypher and two-face) or krilla, hayro or subsetter change version, fetch each
notice again at the new version from the address given in its section, replace the section's
text and update its versions. Also check that no other crate in the tree has gained a NOTICE
file or embedded data. Last refreshed on 2026-10-25, for lawh 0.1.0.

The two fonts lawh bundles are not covered here: their SIL Open Font License 1.1 texts ship next
to the binary as Inter-OFL.txt and Libertinus-OFL.txt.
